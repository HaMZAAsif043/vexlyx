# Vexlyx project

Vexlyx is an MIT-licensed open-source project maintained by Atlantiqs and its contributors.

## Participate

- [Contributing](/project/contributing) explains local setup, code standards, tests, and pull requests.
- [Security](/project/security) explains how to report vulnerabilities privately.
- [Changelog](/project/changelog) records notable release changes.
- [GitHub](https://github.com/atlantiqshq/vexlyx) contains source code, issues, and release history.

For installation or product problems, start with [Troubleshooting](/guide/troubleshooting). Use a security report—not a public issue—when a problem could expose accounts, secrets, customer data, or server control.
